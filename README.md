# First--ALU

# 4-Bit ALU Design Using Verilog

## Project Overview
A 4-bit Arithmetic Logic Unit designed
using Verilog HDL and simulated using
AMD Vivado.

## Operations
1. Addition
2. Subtraction
3. AND
4. OR
5. XOR
6. NOT
7. Increment
8. Pass B

## Tools Used
- Verilog HDL
- AMD Vivado
- Vivado Simulator

## Architecture
Two 4-bit inputs are supplied to the ALU.
A 3-bit select signal chooses the operation.
The result is available at a 4-bit output.

## Verification
Functional simulation performed using
a Verilog testbench.

## Synthesis
Synthesis and resource utilization
analysis performed in Vivado.

## Hardware
No physical FPGA board used.
Simulation-based project.
